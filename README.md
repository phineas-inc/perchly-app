# Perchly Mission Control: live concept prototype

An interactive concept dashboard for small-satellite mission control, shown with sample data.

**Live demo:** https://tahire29-spec.github.io/perchly-app/

This repository contains only the compiled demo. It is a design and front-end concept by Tanishq, not a real product or service. All spacecraft, stations, telemetry and people shown are fictional sample data.

Marketing site: https://tahire29-spec.github.io/perchly/
